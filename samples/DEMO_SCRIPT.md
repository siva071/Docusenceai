# DocuSense AI Demo Script (3–4 minutes)

## 0:00–0:25 — Introduce the workflow

Open the app with `streamlit run app.py`. Introduce DocuSense AI as an offline-first PDF extraction workflow: selectable PDF text first, optional local Tesseract for scan-like pages, page-aware table detection, conservative stitching, validation findings, source evidence, and Excel export. Clarify that validation and evidence are review aids, not correctness guarantees.

## 0:25–1:10 — Digital wide-table sample

Upload `samples/digital_10_column.pdf` and click **Start Processing**. Show the page count, detected table preview, ten extracted columns, and per-page recovery status. Open the Validation Report and Proof Mode; select a cell and review its source page, table coordinates and mapped digital words. Download the workbook and open it to show the table worksheet, `Validation Report`, and `Source Evidence`.

Expected workbook: `samples/outputs/digital_10_column.xlsx`, generated by the real pipeline and checked by `samples/build_demo_samples.py`.

## 1:10–2:00 — Multi-page continuation

Upload `samples/multipage_continuation.pdf`. Show the stitch count and the two pages represented in one table. Point out that the repeated header on page 2 is not duplicated as a data row and the rows retain source page values. Download/open `samples/outputs/multipage_continuation.xlsx` and verify four data rows plus their source pages.

## 2:00–2:50 — Scanned sample and recovery

Upload `samples/scanned_table.pdf`. The current challenge environment does not have Tesseract installed, so show the actionable OCR setup message and failed/manual-review page status. Do not present OCR output as successful. Explain that the retry control becomes available after Tesseract and the configured language data are detected. If demonstrating on a machine with Tesseract installed, retry the failed page and inspect OCR text/evidence before exporting.

No Excel workbook is expected for this scan in this environment because no table was extracted; no OCR values are fabricated.

## 2:50–3:30 — Close

Summarize the existing controls: failed pages remain visible, retries process only selected failed OCR pages, validation never edits source values, and source evidence reports unavailable locations honestly. Mention that complex scans and table layouts still require human review.
